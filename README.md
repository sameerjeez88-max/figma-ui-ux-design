# Finance Website UI/UX Design (Figma)

A modern, clean, and high-converting UI/UX design concept for a personal loans and finance website. This project focuses on a seamless user journey from the homepage to loan application and final submission.

## 🔗 Live Figma Prototype
You can view the interactive design and prototype directly in Figma:
👉 [View Live Design on Figma](https://www.figma.com/design/9us9uLP2IiAMgyCXDViQ7a/Finance-Website---UI-UX-Concept?node-id=0-1&m=dev&t=AOv5PwBzhNRayWyT-1)

## ✨ Key Features
- **Modern Dark & Light Theme:** Clean navy, emerald, and white color palette.
- **User-Centric Flow:** 6-step loan application process with a progress bar.
- **Responsive Design:** Optimized for both desktop and mobile screens.
- **Interactive Elements:** Hover states, dropdowns, and form validations.
- **Typography:** Clean and readable font pairing for better UX.
- **Custom Design System:** Reusable components and styles.

## 🛠️ Tools Used
- **Figma** (For UI/UX Design, Prototyping, and Design System)
- **Adobe Photoshop** (For image assets and mockups)

## 🖼️ Project Screens
1. **Homepage:** Featuring a clean hero section, loan calculator, and trust badges.
2. **Application Step 1:** Loan amount selection and visual progress bar.
3. **Application Submitted:** Success page with clear next steps and summary.
